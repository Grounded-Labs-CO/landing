Arquitectura

Stack: Next.js 16 (App Router, React 19) + Convex + Tailwind v4 + shadcn/ui + next-themes + lucide-react. Branding 2A: tinta #0E1214 / panel #1C2427 / terracota #B4552B, IBM Plex Sans 200/300 + Mono 400/500/600.

Convex

convex/schema.ts – user_roles, leads, workshop_registrations, courses, course_sections, course_items, sample_profiles, sample_files, user_profiles (displayName, phone)
convex/auth.ts – @convex-dev/auth con Email (Resend, magic link, from noreply@grounded-labs.com) + Password (secundario) + afterUserCreatedOrUpdated (pending)
convex/queries.ts – getUserRole, listLeads (admin-only)
convex/mutations.ts – createLead, saveUserProfile
convex/admin.ts – approveUser, promoteByEmail, markRegistrationPaid, addStudent (bootstrap), listPendingUsers, listRegistrations
convex/courses.ts / material.ts – catálogo y material

Frontend

  • ConvexClientProvider (ConvexAuthProvider + NEXT_PUBLIC_CONVEX_URL, fallback placeholder)
  • AuthGuard → /signin (redirectTo /estudiantes en magic link)
  • useRole() → {role, isAdmin, isPending, isLoading}
  • Layout: IBM Plex Sans/Mono, ThemeProvider (dark), Header sticky tinta #0E1214/90 blur, max-w 1240
  • Alias @/* → src/*
  • Páginas: / (corporativa 2A), /workshops/finanzas-personales-ia (ficha sin header, CTA marco), /signin (email default + contraseña secundaria), /admin, /estudiantes
